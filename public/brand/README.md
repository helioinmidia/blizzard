# Marca

Coloque aqui a logo da Vertex Softwares:

- `logo.svg` (ou `logo.png`): símbolo quadrado, usado no painel lateral e na tela inicial.
  SVG com fundo transparente fica melhor sobre o fundo escuro.

Os arquivos desta pasta ficam fora do git e são servidos direto pelo nginx (`/brand/…`), então basta
copiar e recarregar a página; não precisa rebuildar. Sem o arquivo, a central usa o símbolo padrão.
